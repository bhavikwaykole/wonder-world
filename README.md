# WanderWorld – Travel Blog Website

A responsive travel blog website featuring three tourist destinations:
- Amalfi Coast, Italy
- Swiss Alps, Switzerland
- Tokyo, Japan

## Files
- `index.html` – webpage structure and destination information
- `style.css` – design and responsive layout
- `script.js` – smooth scrolling interaction

## Run locally
1. Extract the project folder.
2. Open the folder in VS Code.
3. Open `index.html` in a browser (or use the Live Server extension).

The destination and hero images are loaded from Unsplash, so an internet connection is needed to display them.

## Deploy using GitHub Pages
1. Create a new public repository on GitHub, for example `travel-blog-website`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish the site. Your website link will appear in the Pages section.
